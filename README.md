# Campus Information & Attendance Web Portal
HTML, CSS, JavaScript, PHP (PDO), MySQL.

## Menjalankan (lokal)
1. Pasang XAMPP, aktifkan Apache dan MySQL.
2. Salin folder ini ke `htdocs/campus-portal`.
3. Impor `database.sql` lewat phpMyAdmin.
4. Cek kredensial di `config.php`.
5. Buka `http://localhost/campus-portal/`, daftar akun, lalu masuk.

## Catatan
GitHub Pages tidak menjalankan PHP/MySQL. Repositori ini untuk kode sumber; demo hidup butuh hosting PHP.
